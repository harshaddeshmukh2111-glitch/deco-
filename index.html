01 / THE BASICS

What exactly is a CPU?

The CPU executes program instructions and helps manage operations across a computer system.

⌘

Processes instructions

Reads instructions from memory, interprets them, and carries out the required operations.

03 / THE INSTRUCTION CYCLE

How does a CPU work?

A simplified view of how a processor handles an instruction.

01↓

Fetch

The CPU retrieves the next instruction from memory.

02⌕

Decode

The control logic interprets what the instruction asks the CPU to do.

03∑

Execute

The CPU performs the operation, such as a calculation or data movement.

04↻

Store / continue

Results may be written to a register or memory, then processing continues.

GHz

Does higher GHz always mean faster?

No. Clock speed is only one factor. A newer design may do more work per clock, and performance depends on the specific task and processor.
